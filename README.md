\# Program Laundry Go



\## 1. Nama dan Deskripsi Project



\*\*Nama Project:\*\* Program Laundry Go



Program Laundry Go merupakan aplikasi sederhana berbasis bahasa pemrograman Go yang digunakan untuk menghitung biaya laundry berdasarkan berat cucian pelanggan. Program ini juga menghitung total pembayaran, memeriksa kecukupan uang, dan menghitung kembalian.



\## 2. Fitur-Fitur Program



1\. Menampilkan nama dan NIM mahasiswa.

2\. Memasukkan berat cucian dalam kilogram.

3\. Menghitung biaya laundry berdasarkan berat cucian.

4\. Menambahkan biaya antar.

5\. Memeriksa apakah uang pembayaran mencukupi.

6\. Menghitung kembalian pelanggan.

7\. Menampilkan struk pembayaran.

8\. Memvalidasi berat cucian agar tidak bernilai nol atau negatif.



\## 3. Teknologi yang Digunakan



\- Bahasa pemrograman: Go (Golang).

\- Version Control: Git.

\- Repository online: GitHub.

\- Text Editor: Visual Studio Code / Notepad.



\## 4. Cara Menjalankan Program



Pastikan Go sudah terinstal di komputer.



Langkah-langkah menjalankan program:



1\. Buka terminal.

2\. Masuk ke folder project.

3\. Jalankan perintah berikut:



```bash

go run main.go

```



4\. Masukkan berat cucian ketika diminta.

5\. Masukkan jumlah uang yang diterima.

6\. Program akan menampilkan struk pembayaran dan kembalian.
